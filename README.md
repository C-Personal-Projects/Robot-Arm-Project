# Robot Arm Project
This repository contains all of the files pertaining to my robot arm project. This project is a 3D printable, easy to assemble, low cost, manually operated, 4-axis robotic arm powered by an Arduino Uno. The arm attachments are interchangable through a system of magnetic brackets.
